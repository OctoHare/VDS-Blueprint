# Политика безопасности

## 🛡️ Как сообщить об уязвимости

Если вы обнаружили проблему с безопасностью в скриптах, конфигурациях или рекомендациях этого проекта — пожалуйста, **НЕ создавайте публичных задач (Issues) и не пишите в открытые чаты**.

Чтобы защитить пользователей, сообщайте об уязвимостях приватным способом:
* Через [GitHub Private Vulnerability Reporting](https://github.com/OctoHare/VDS-Blueprint/security/advisories/new) *(если функция включена в репозитории)*.
* Или приватным сообщением автору проекта.

### Пожалуйста, укажите в сообщении:
* Описание уязвимости и потенциальный риск.
* Шаги для воспроизведения проблемы (с удалением всех личных ключей, IP-адресов и паролей).
* Версию ОС и окружение, где проблема была обнаружена.

Мы постараемся изучить проблему и подготовить исправление в кратчайшие сроки. Пожалуйста, не разглашайте информацию о дыре в безопасности публично до выхода патча.

# Security Policy

## 🛡️ Reporting a Vulnerability

If you discover a security vulnerability within the scripts, configurations, or guide materials of this project, please **DO NOT open a public Issue or discuss it in public channels**.

To protect users, please report security issues privately:
* Via [GitHub Private Vulnerability Reporting](https://github.com/OctoHare/VDS-Blueprint/security/advisories/new).
* Or via a private message to the project maintainer.

### Please include:
* A description of the vulnerability and its potential impact.
* Steps to reproduce the issue (with all secrets, private keys, and IP addresses removed).
* OS version and environment details.

We will review the report and attempt to issue a fix as soon as possible. Please allow time for a patch to be released before disclosing details publicly.
